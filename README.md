# 🏟️ Elite Sports Complex

A modern full-stack sports complex management platform built to simplify sports facility booking, user management, and event coordination. The project provides an interactive and responsive experience for players, admins, and sports enthusiasts.

## Created by HarshVardhan Parashar and Harshita Sharma.

## 🌐 Live Demo
🔗 https://elite-sports-complex.vercel.app

## 🚀 Features
- 👤 User Authentication & Authorization
- 🏸 Sports Court Booking System
- 📅 Event & Match Scheduling
- 🌦️ Real-Time Weather Updates using Weather API
- 🏆 Sports Activity Management
- 📊 Admin Dashboard
- 📱 Fully Responsive UI
- ⚡ Fast and Interactive Experience
- 🔐 Secure Backend Integration
- ☁️ MongoDB Database Support


## 🌦️ Weather API Integration

The platform includes weather forecasting support to help users plan outdoor sports activities efficiently.

### Weather Features
- Real-time weather updates
- Temperature display
- Humidity and wind speed tracking
- Weather conditions for outdoor games
- Dynamic weather icons

### API Used
- OpenWeatherMap API

## 📂 Project Structure

The project follows a modular MERN stack architecture where authentication, sports bookings, event management, and weather services are handled through separate backend modules and organized frontend components.
